База знаний IMS

  • IMS — это система учёта и управления инвентарём для школы или организации.
  • В системе реализовано разграничение прав: администратор и пользователь.
  • Все действия пользователей и администраторов логируются.
  • Доступна работа через веб-интерфейс с поддержкой мобильных устройств.

  • Администратор — полный доступ: управление инвентарём, пользователями, заявками, просмотр логов, экспорт данных.
  • Пользователь — просмотр инвентаря, создание заявок, возврат предметов.
  • Роль администратора назначается через список ADMIN_LOGINS в настройках.

Способы входа в систему
  • Логин и пароль — стандартный способ входа. Доступен всем пользователям.
  • ID-карта — альтернативный способ входа по коду карты. Для использования необходимо настроить код карты в профиле.
  • Двухфакторная аутентификация — повышенный уровень безопасности, требующий ввода логина, пароля и кода ID-карты.
Настройка ID-карты
  • Перейдите в раздел "Профиль" в меню навигации.
  • В блоке "ID-карта и безопасность" введите код вашей карты.
  • Код можно ввести вручную или отсканировать с помощью сканера штрих-кода.
  • После установки кода вы сможете входить в систему, используя только ID-карту.
  • Код карты можно изменить в любой момент в настройках профиля.
Двухфакторная аутентификация (2FA)
  • Для включения 2FA необходимо сначала настроить код ID-карты.
  • В профиле пользователя включите переключатель "Двухфакторная аутентификация".
  • После включения 2FA при каждом входе потребуется ввести:
    • Логин и пароль
    • Код ID-карты (можно отсканировать)
  • 2FA можно отключить в любой момент в настройках профиля.
  • Рекомендуется включать 2FA для администраторов и пользователей с доступом к важным данным.
Работа со сканером штрих-кода
  • Для ввода кода ID-карты можно использовать сканер штрих-кода.
  • Важно! По умолчанию большинство сканеров добавляют Enter после кода. Для корректной работы отключите постфикс в настройках сканера.
  • Если сканер не работает — попробуйте подключить его к другому USB-порту или перезагрузить страницу.
  • Подробнее о настройке сканера см. в разделе "Работа со сканером штрихкодов".
Безопасность
  • Все пароли хранятся в зашифрованном виде.
  • Каждый вход в систему логируется с указанием способа аутентификации.
  • При подозрительной активности обратитесь к администратору.
  • Рекомендуется регулярно менять пароль и не использовать один пароль для разных сервисов.

  • Вы можете просматривать список доступного инвентаря и его состояние.
  • Для поиска используйте строку поиска над таблицей инвентаря.
  • Доступные фильтры позволяют быстро найти нужный предмет по состоянию или названию.
  • Если предмет недоступен, вы увидите его статус (например, "выдан" или "на ремонте").
  • Для возврата предмета используйте раздел "Возврат" в личном кабинете.
  • Если вы не видите нужный инвентарь — обратитесь к администратору.

  • Вы можете создать заявку на получение или ремонт/замену инвентаря.
  • Для этого перейдите в раздел "Заявки" и заполните форму, указав инвентарный номер и комментарий (при необходимости).
  • Инвентарный номер можно ввести вручную или с помощью сканера штрихкодов/QR-кодов.
  • После отправки заявки вы увидите её статус (ожидание, одобрено, отклонено).
  • Историю всех ваших заявок можно посмотреть в этом же разделе.
  • Если ваша заявка долго не рассматривается — обратитесь к администратору.

  • Если вы больше не используете предмет, оформите возврат через раздел "Возврат".
  • Выберите нужный предмет из списка и подтвердите возврат.
  • После возврата предмет снова станет доступен для других пользователей.
  • Если возникли проблемы с возвратом — обратитесь к администратору.

  • Планирование закупок доступно только администраторам.
  • Пользователь может просматривать только уже добавленные предметы.

  • Пользователь может выгрузить список инвентаря в формате CSV или JSON (если разрешено администратором).
  • Для этого используйте кнопки "Экспорт" в разделе "Отчёты".
  • Экспорт логов доступен только администраторам.

  • Все действия пользователей и администраторов фиксируются в системных логах.
  • Просмотр, экспорт и удаление логов доступны только администраторам.
  • Логи содержат информацию о времени, IP-адресе, действии, статусе ответа и др.

  • Для ускорения ввода инвентарных номеров можно использовать сканер штрихкодов или QR-кодов.
  • Важно! По умолчанию большинство сканеров добавляют Enter (или другой постфикс) после кода. Для корректной работы отключите постфикс в настройках сканера.

  • Проверьте документацию к вашему сканеру для изменения настроек.

  • В случае проблем обратитесь к администратору или в поддержку.
